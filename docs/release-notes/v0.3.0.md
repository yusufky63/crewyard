Crewyard 0.3.0 makes agents ask far less, adds goal drafting to the task assistant and gives the Crew graph real actions. It also fixes two problems found while testing 0.2.0 on a real machine.

## Fewer approvals

Codex on Windows wraps every command in `powershell.exe -Command '…'`, so in 0.2.0 each read and each `git status` was an Inbox approval.

- Crewyard now looks inside a runner's shell wrapper and checks each statement of the script separately.
- Inside a step's own worktree, these run without asking: reads and local git (`Get-Content`, `Get-ChildItem`, `Select-String`, `rg`, `git status/diff/log/show`, `git add`, `git commit`) and the project's own test and build commands.
- **Allow always** now saves the command that ran, not the wrapper around it.
- These still ask:
  - paths outside the worktree, a `..` step, `~` and secret files;
  - pipes, redirection and substitution.
- Pushes, hard resets and package installs stay high risk.

## Task assistant and goals

- **`draft_goal`:** the assistant can turn a conversation into an Orchestra goal.
  - It fills the composer in Orchestra mode with the goal, a planner and a suggested budget, and adds a goal card to its drafts.
  - Nothing is planned until you press Plan goal, which shows the planning cost first.
- **Autopilot** (opt-in) can now plan a goal and approve its first plan within the limits you set. Every estimate must be known, each task must fit the per-task limit, the total must fit the day limit and parallel tasks must fit the concurrency limit. Replans and added tasks stay with you ([ADR 0022](https://github.com/yusufky63/crewyard/blob/main/docs/adr/0022-assistant-goals.md)).
- The assistant's instructions now spell out how to change or remove its own drafts, and say who can do what it cannot.

## Crew graph

- **Task node menu** (right-click, Shift+F10 or the Menu key):
  - open details, open changes;
  - retry failed steps;
  - add a follow-up step;
  - pause all, resume all;
  - cancel task;
  - on a proposal: approve, or change the AI of every step.
- **Change AI before it starts:** for an approved step that has not run yet. Once it runs, Change AI is the existing handoff.
- **Run again with another AI:** for a finished step. The new step waits for your approval.
- **Standby agents** are now a small badge on their step (`Standby: Gemini CLI +1`) instead of full tiles. The badge opens the order, which you can change until the step starts. A real handoff still shows as its own tile with the amber dashed line.

## Fixes

- **Agent CLIs were shown as not found** right after start on a busy Windows machine. The lookup no longer starts `where.exe`, whose five-second limit could expire under load. It reads the PATH folders itself, in the same order and never in the current folder.
- **ChatGPT and Google sign-in were unreachable** without an API key: the option sat only in a provider's own dialog, which a provider without a key does not have. The Connect dialog now offers **Sign in with ChatGPT instead** (or Google) directly.

## Release and site

- Plain versions such as 0.3.0 are now published as normal releases, and GitHub marks the newest one Latest. Only tags with a pre-release part, such as `v0.4.0-rc.1`, are pre-releases.
- The website lists this release on its download and changelog pages within the hour.

## Known limits

- The macOS and Linux packages are built and smoke-started on GitHub's runners but have not been tried on a real machine yet.
- No build updates itself yet; download the next release from the releases page.
