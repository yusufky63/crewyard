Crewyard 0.2.0 is the first public release. The repository is now public under the MIT licence, and this is the first build for macOS and Linux as well as Windows. It is a pre-release: builds are unsigned and do not update themselves.

## Orchestra, Crew and Solo

The composer has three ways to run work, and **Orchestra** is the default when a profile can plan read-only ([ADR 0019](https://github.com/yusufky63/crewyard/blob/main/docs/adr/0019-orchestra-goals.md)).

- **Orchestra:**
  - You write a goal. One read-only planning run, with its estimate and ceiling on the button, returns a plan of up to eight tasks with their dependencies and the files each will change.
  - One click approves it with a prefilled goal budget. Tasks that touch the same files are ordered for you.
  - The scheduler releases tasks in order, at most two at a time per goal. Each finished task merges into the goal's own branch, in Crewyard's own worktree.
  - A last review of all changes opens the pull request gate. You open the pull request.
- **Crew:** the flow from 0.1: one task, a proposed crew you approve.
- **Solo:** one agent, started by your click on its shown estimate. It is never remembered as the default.
- **Your click is still needed for:** a revised plan, a replan, an added task, a research report that code builds on, and spend past any cap.
- **Always yours:** push, pull requests, merges into your branches and deletes.
- **Pausing:** `Pause goal` and `Pause all goals` hold planning, retries and review loops too.
- **New project daily cap.** The project's daily budget from the setup wizard is now enforced on every paid run and fallback.

## External access over MCP

An agent you run outside the app (Claude Code, Claude Desktop, Cursor, Codex) can connect to Crewyard as an MCP server ([ADR 0021](https://github.com/yusufky63/crewyard/blob/main/docs/adr/0021-external-mcp.md)).

- **What it can do:**
  - read projects, tasks, reports, the Inbox, spend and settings;
  - add a folder as a project;
  - tighten project settings;
  - change test and build commands and MCP servers;
  - propose tasks.
- **What it never does:** approve, start, push, merge, delete, answer the Inbox or read a key.
- **Off by default.** Settings → External access turns it on, gives each client its own token (kept with DPAPI) and a copyable config, and revokes a client. No TCP port is opened.

## Task assistant

- **Live state:** the conversation shows what the assistant is doing under your message: starting, thinking, or the latest call with the time since the turn began.
- **Replies:** rendered as text-only Markdown with Copy, Quote and Make drafts from this; code blocks copy.
- **Message box:** clearer, with a primary Send and a Stop.
- **Read tools:** the assistant reads much more of the app: tasks, reports, crews, the Inbox, events, spend and limits, profiles, settings, local git, problems and your instruction files ([ADR 0018](https://github.com/yusufky63/crewyard/blob/main/docs/adr/0018-assistant-read-tools.md)).
- **Drafts:** it can refine its own open drafts.
- **Open task** now takes you to the task from anywhere.

## Interface

- **Bottom panel:** it folds to its tab strip from a toggle in its head, like the sidebar and the inspector, and never stops anything when folded.
- **Research reports:** in the inspector they read as a document, with a severity bar that filters, expandable findings, `file:line` links into the Files tab, and a Suggested tasks block and tab.
- **Colours:** red, amber and green now mark the controls and states that mean them: Stop, Turn on and Turn off, risk, verdicts.
- **New Guide screen** (`G W`): the three ways to run work, the flow, a getting-started checklist read from your setup, what else Crewyard does, and questions.

## Providers

- **Gemini CLI's Google sign-in** is labelled for Gemini Code Assist Standard or Enterprise accounts. Google stopped serving personal accounts in Gemini CLI on 2026-06-18; use a paid Gemini API key instead.
- **New models by API key:** Gemini 4 Argon and Gemini 3.8 Flash, with Gemini CLI and OpenCode.
- **Claude** profiles stay API-key only.

## Platforms and project

- **Platforms:** Windows 11 x64; macOS 13 or later on Apple silicon and Intel (ad-hoc signed, not notarized); Linux x64 as AppImage and .deb.
- **Checksums:** every release carries `SHA256SUMS.txt`.
- **Licence:** MIT, Copyright (c) 2026 Yusuf.
- **Docs:** SECURITY.md and CONTRIBUTING.md are new.
- **Website:** lists every release as it is published.

## Known limits

- macOS and Linux packages are built and smoke-started on GitHub's runners but have not been tried on a real machine yet. Reports are welcome.
- Orchestra's planning estimate is a fixed heuristic until real planning runs measure it.
- No build updates itself yet; download the next release from the releases page.
